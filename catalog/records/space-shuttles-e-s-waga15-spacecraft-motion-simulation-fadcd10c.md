## System Engineer Summary

This project is an interactive 3D spacecraft motion simulation developed using the powerful Three.js
web graphics library. It aims to provide a realistic visual experience of launching a rocket from a
ground-based launch pad, simulating the basic flight phases of the Space Shuttle, including the
launch tower displacement and liftoff phases.

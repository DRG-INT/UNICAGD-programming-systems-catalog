## System Engineer Summary

A MATLAB GUI for estimating some properties of turbines, the code is mainly based on Mattingly's
"Elements of Propulsion". This repository is made for educational purposes, it does solve the
problems in the book so it would be a useful resource for students. See the interface screenshots or
just run the code, it's pre-loaded with examples!

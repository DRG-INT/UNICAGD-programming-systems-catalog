## System Engineer Summary

PEM Encoding (RFC 7468) for PKIX, PKCS, and CMS Structures, implementing a strict subset of the
original Privacy-Enhanced Mail encoding intended specifically for use with cryptographic keys,
certificates, and other messages. Provides a no_std-friendly, constant-time implementation suitable
for use with cryptographic private keys.

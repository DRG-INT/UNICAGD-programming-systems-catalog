## System Engineer Summary

JSON4Lua and JSONRPC4Lua implement JSON (JavaScript Object Notation) encoding and decoding and a
JSON-RPC-over-http client for Lua.

## Operational Role

persistence, interoperability, and compatibility boundaries.

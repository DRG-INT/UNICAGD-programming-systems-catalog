## System Engineer Summary

Chat2DB is a free, cross-platform, local-first database client and SQL workspace for developers,
DBAs, analysts, and data teams. Connect to 40+ databases, manage data, edit and run SQL, and use
your own AI model to generate, explain, and optimize queries. Available on desktop, web, Docker, and
CLI, with MCP support.

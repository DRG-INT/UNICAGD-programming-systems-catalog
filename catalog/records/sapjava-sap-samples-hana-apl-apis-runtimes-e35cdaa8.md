## System Engineer Summary

Code examples for SAP HANA Automated Predictive Library (APL). It provides simple APL SQL examples
covering all APL APIs, as well as reference implementations of the runtimes needed when predictive
models are exported in C++, Java, or JavaScript for massive or real-time scoring.

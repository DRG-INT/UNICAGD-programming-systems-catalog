## System Engineer Summary

The SpeechBrain project aims to build a novel speech toolkit fully based on PyTorch. With
SpeechBrain users can easily create speech processing systems, ranging from speech recognition (both
HMM/DNN and end-to-end), speaker recognition, speech enhancement, speech separation, multi-
microphone speech processing, and many others.

## System Engineer Summary

A comprehensive C++ framework featuring efficient user-space threading (coroutine with work-
stealing), I/O, networking, RPC, HTTP, etc., and used extensively in Alibaba. It is compatible with
C++ 14/17/20/23, Linux, MacOS, x86-64, ARM64, gcc and clang. Apache2

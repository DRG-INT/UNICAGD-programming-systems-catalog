## System Engineer Summary

A tiny low-level library that provides platform-specific standard locations of directories for
config, cache and other data on Linux, Windows, macOS and Redox by leveraging the mechanisms defined
by the XDG base/user directory specifications on Linux, the Known Folder API on Windows, and the
Standard Directory guidelines on macOS.

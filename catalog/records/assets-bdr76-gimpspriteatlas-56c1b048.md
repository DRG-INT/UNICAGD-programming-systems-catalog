## System Engineer Summary

GIMP plug-in to create a spriteatlas (aka spritetexture or spritesheet). Takes all layers as images
and compiles them into one sprite atlas texture, using a 2D packing algorithm so that the final
texture image takes as little space as possible. Also outputs a TexturePacker JSON, LibGDX, CSS or
XML coordinates file.

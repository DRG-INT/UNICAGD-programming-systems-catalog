## System Engineer Summary

A package to run and fill Jupyter Notebooks within GNU Octave. Evaluate long-running Octave Jupyter
Notebooks on a computing server without permanent browser connection. Included in Octave core since
version 7.1.0. No need to install this package in recent Octave versions.

## Operational Role

For a systems engineer, jupyter-notebook belongs in the Octave inventory as part of request routing,
middleware policy, service structure, and deployment surface.
